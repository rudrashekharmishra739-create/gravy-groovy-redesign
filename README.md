# Gravy Groovy — Website Redesign Concept

A modern, SEO-friendly and performance-optimized redesign concept for **Gravy Groovy**, an Indian restaurant in Gomti Nagar, Lucknow.

> Redesign concept only — not the official site. Built as a static multi-page website.

## Pages
- `index.html` — Home (hero, story, offerings, gallery preview, testimonials, visit)
- `about.html` — Story, food philosophy, experience, team, catering
- `menu.html` — Full menu with categories and pricing
- `gallery.html` — Visual tour (masonry)
- `contact.html` — Enquiry form, address, map, hours
- `order.html` — Online ordering / reservation options + quick order form

## SEO & Performance features
- Semantic HTML5 landmarks (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Unique `<title>` and meta description per page
- Canonical URLs, Open Graph + Twitter Card tags
- JSON-LD structured data (`Restaurant` schema) on home & contact
- `sitemap.xml` and `robots.txt`
- Descriptive alt text on all images
- Lazy-loaded images with dimensions (CLS prevention)
- Preconnected Google Fonts, single shared CSS/JS
- Mobile-first responsive layout, sticky accessible nav
- Skip link, focus states, ARIA labels, color contrast

## Run locally
Open `index.html` in any browser. No build step required.

## Tech
Plain HTML, CSS, vanilla JS. No dependencies.
